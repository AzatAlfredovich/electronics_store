# **API для управления сети по продаже электроники**

Проект реализует иерархическую структуру торговой сети с помощью API-интерфейса и управлением через административную панель.

Сеть состоит из трёх уровней:

- завод (factory)
- розничная сеть (retail)
- индивидуальный предприниматель (entrepreneur)

Каждое звено сети может ссылаться на одного поставщика, формируя иерархию (A > B > C).

## Основной функционал


### Административная панель

В админ-панели реализовано управление объектами сети:

- создание и редактирование звеньев сети
- управление продуктами
- отображение иерархии поставщиков
- фильтрация по городу
- ссылка на поставщика
- admin action для очистки задолженности перед поставщиком

---

### API

- Получение списка объекта или объектов, создание, редактирование и удаление.
- Поле **debt_to_supplier** запрещено для изменения через API.
- Фильтрация через "**?example=**", поиск по основным полям через "**?search=**" и сортировка через "**?ordering=**".

---

### Аутентификация

Используется JWT-аутентификация.

Получение токена:
```
POST /api/token/
```
Обновление токена:
```
POST /api/token/refresh/
```

Доступ к API имеют **только активные сотрудники** (`is_active=True` и `is_staff=True`).

## Установка

- Клонируйте репозиторий и перейдите в папку проекта через `cd ProjectName`
```
git clone https://github.com/AzatAlfredovich/electronics_store.git
```
- Создайте виртуальное окружение и активируйте его

```
python -m venv .venv
```

Windows: `.venv\Scripts\activate`

Linux / Mac: `source .venv/bin/activate`

- Установите зависимости `pip install -r requirements.txt`
- Создайте файл .env по шаблону .env.sample. и заполните его
- Примените миграции `python manage.py migrate`
- Создайте суперпользователя `python manage.py createsuperuser`
- Запустите тесты `coverage run --source=. manage.py test` и сформируйте отчет `coverage report`
